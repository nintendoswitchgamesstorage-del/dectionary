LEXICAL ALCHEMY — WINDOWS PORTABLE EDITION

For 64-bit Windows 10/11.

1. Double-click LexicalAlchemy.exe.
2. Wait for the first startup to prepare the two bundled source PDFs.
3. Your default browser opens the laboratory. If it does not, click
   "Open laboratory" in the small launcher window.
4. Keep the launcher window open while working. Click Exit when finished.

No Python, Node.js, installer, API key, or administrator access is required.
The interface, Python runtime, starter PDFs, and public dictionary caches
are included. Default research and word-making work locally.

Your PDFs, indexes, annotations, and projects are saved in:
    %LOCALAPPDATA%\LexicalAlchemy
They remain there when the executable is moved or updated. Save named
projects in the app; the browser draft is only a convenience and the local
server URL can change on a restart. Back up the data folder to keep your work.

The app uses a private loopback server and your existing browser. Closing
the browser does not quit the launcher. It does not open a public network
service. The executable is unsigned, so Windows may show a SmartScreen
prompt. No publisher signature is claimed.

Online dictionary refresh requires Internet access. Optional model assistance
requires your own provider configuration and explicit opt-in. Game-world
leads remain labeled unverified where their references were not retrieved.
German Hunspell data attests spelling, not meaning. OCR is not bundled.

If startup fails, see:
    %LOCALAPPDATA%\LexicalAlchemy\logs\desktop.log

Source attribution and dictionary license details accompany this edition in
SOURCES.md and are also bundled inside the executable.

Build verification uses Wine64 on Linux. This does not replace native
Windows hardware testing or code signing.
