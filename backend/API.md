Run from the repository root with `uvicorn backend.app:app --host 0.0.0.0 --port 8000`. Interactive endpoint documentation is at `/docs`; the OpenAPI schema is at `/openapi.json`.

All application endpoints begin with `/api`:

- `GET /health` reports local service readiness. `GET /providers` reports configured model and dictionary cache states without revealing credentials.
- `GET /sources` lists persistent PDF metadata. `POST /sources` accepts multipart field `files` (multiple PDFs, at most 20 at a time, each at most 32 MiB). Returns `sources`, `uploaded`, and `warnings`; byte-identical PDFs reuse the existing source. `DELETE /sources/{id}` removes the original file and its local index. `POST /sources/{id}/reprocess` rebuilds that source. `GET /sources/{id}/file` serves the original PDF. Source states are `ready`, `partial`, `scanned`, and `error`; OCR is not bundled.
- `GET /sources/search?q=...&source_ids=id,id` searches actual extracted pages. An empty selection searches all sources. Results contain `document_id`, `filename`, the actual one-based PDF `page`, a concise `excerpt`, and a local lexical `score`.
- `POST /analyze` accepts `{concept,use_model?:false}`. Default concept interpretation is an explicit theme/keyword heuristic. `use_model:true` requires `LEXICAL_MODEL_API_KEY` and optionally `LEXICAL_MODEL_NAME` (default `gpt-4.1-mini`); `OPENAI_API_KEY` and `OPENAI_MODEL` remain supported fallbacks. The concept is sent to OpenAI. Original PDFs and the full document index are not sent.
- `POST /research` accepts `{concept,interpretation?,languages:[],source_ids:[],include_web:false,include_games:true,dimensions:[{name,weight}]}`. This engine uses local lexical matching and optional real public-dictionary snapshot retrieval. It does not claim model-based semantic retrieval. Selection limits PDF-derived candidates; dictionary and game filters are independent. Unverified editorial leads remain labeled. `use_model:true` is rejected with an explanation; model interpretation may be edited and passed as `interpretation`.
- `POST /forge` accepts `{concept,roots:[{text,language,meaning}],level,count,seed?,use_model?:false}`. Levels: `conservative`, `inventive`, `abrasive`, `surreal`, `radical`. Default generation uses explicit local transformations; OpenAI mode sends the concept and roots selected by the user (which may include source snippets). Original PDFs and the full document index are not sent. Every generated entry is `coined`.
- `GET /projects` lists saved projects. `POST /projects` accepts `{id?,name,concept,analysis,candidates,shortlist,notes,dimensions,forge_history?}` and returns the saved complete project. `GET /projects/{id}` loads it; `DELETE /projects/{id}` removes it. Shortlists may contain candidate IDs or full candidate objects. Notes may be text or a map of candidate IDs to annotations.
- `POST /export` accepts `{format:'markdown'|'csv'|'pdf',project:{...}}` and returns a downloadable UTF-8 Markdown, UTF-8 CSV, or Unicode PDF. Evidence labels, citations, page numbers, components, caveats, fit explanations, annotations, and shortlist membership are preserved.

Data remains in `.data/lexical.sqlite3`, `.data/sources/`, and `.data/dictionaries/` by default. Set `LEXICAL_DATA_DIR` to change the local path. Source ingestion and deletion persist across restarts. On the first startup, the two supplied source PDFs are imported from `/workspace/attachments` when present; the implementation-guide PDF is never imported as vocabulary. Deleted bootstrap PDFs do not reappear automatically. Set `LEXICAL_BOOTSTRAP_PDFS=0` to disable this, or use `python -m backend.import_sources path/to/source.pdf` explicitly.

Outbound dictionary retrieval downloads public snapshots and caches them locally. It never uploads documents. Integrations cover Webster English, Make Me a Hanzi Chinese characters, FreeDict Latin–English, French–English, and English–Modern Greek translations, and the igerman98 German Hunspell spelling dictionary. German spelling entries do not claim verified meanings; editorial senses stay separate and unverified. Modern Greek lookup is never returned as an Ancient Greek attestation. Mirror source URLs and the actual retrieval date accompany returned entries. First downloads are larger than per-word API requests; failed network requests return visible partial-result warnings. Dictionary source licenses and limitations are documented in `SOURCES.md` at the repository root. No provider is required for PDF research, local interpretation, local forge, saving, or exports.
